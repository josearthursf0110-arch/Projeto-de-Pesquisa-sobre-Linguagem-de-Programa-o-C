# Projeto de Pesquisa – Linguagem de Programação

##  Sobre o Projeto

Este repositório foi criado para armazenar os materiais desenvolvidos na atividade da disciplina **Tópicos Essenciais para Programação**, utilizando conceitos de **Metodologia Ágil** para organização e divisão das tarefas da equipe.

O objetivo do trabalho é pesquisar uma linguagem de programação, reunindo informações importantes sobre sua história, criadores, empresas que utilizam e curiosidades.

##  Linguagem Escolhida
- C

## Objetivo

Pesquisar e documentar informações sobre a linguagem escolhida, organizando o desenvolvimento do trabalho por meio de práticas ágeis, como:

- Divisão de tarefas;
- Organização por etapas;
- Controle de progresso;
- Planejamento de entregas;
- Trabalho colaborativo.


## Metodologia Ágil Utilizada

A equipe utilizou princípios de **Metodologia Ágil** para organizar o desenvolvimento do trabalho, e contribuição por meio do Github.

### Organização das tarefas:
- Planejamento inicial;
- Divisão de responsabilidades;
- Acompanhamento do progresso;
- Controle de prazos;
- Revisão final.

Este projeto permitiu compreender melhor a linguagem estudada, além de desenvolver habilidades de organização, pesquisa e trabalho em equipe através da aplicação de conceitos de metodologia ágil.
